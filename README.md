# 🥗 MacroSnap – AI Vision Nutrition Chatbot

MacroSnap is an AI-powered nutrition chatbot that analyzes food images and provides nutritional insights. It identifies food items from meal images and provides estimated calories, protein, carbohydrates, fats, and fiber.

Users can also chat with the AI about their meals, receive nutritional insights and healthier food suggestions, summarize conversations, and send nutrition summaries directly to WhatsApp.

## Live Demo

https://macrosnap-baehkvanarappnpbhainvkd.streamlit.app

## Key Features

• Analyzes meal images using AI  
• Identifies food items from uploaded images  
• Provides estimated calorie information  
• Provides estimated protein, carbohydrates, fats, and fiber  
• Allows users to chat with AI about their meals  
• Provides nutritional insights and healthier food suggestions  
• Summarizes nutrition conversations  
• Sends nutrition summaries directly to WhatsApp  

## Technologies Used

• Python  
• Google Gemini AI  
• Streamlit  
• Twilio WhatsApp API  
• GitHub  

## How It Works

• User uploads an image of their meal  
• Gemini AI analyzes the food image  
• Food items are identified  
• Nutritional information is estimated  
• User can chat with the AI about the meal  
• AI provides nutritional insights and healthier suggestions  
• Conversation can be summarized  
• Nutrition summary can be sent directly to WhatsApp
